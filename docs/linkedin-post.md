Estou desenvolvendo o MiniGPT Lab, um projeto para estudar na prática como modelos de linguagem funcionam por dentro.

Em vez de apenas consumir uma API de IA, estou implementando um Transformer decoder-only em PyTorch, incluindo causal self-attention, embeddings posicionais, treinamento autoregressivo e geração de texto.

O projeto também inclui uma etapa de avaliação com loss e perplexity, testes automatizados e uma API com FastAPI. A próxima etapa é comparar o modelo treinado do zero com um modelo pré-treinado usando uma metodologia consistente, registrando métricas e limitações.

A proposta é aprender e demonstrar engenharia de LLMs com experimentos reproduzíveis, código aberto e resultados mensuráveis.
